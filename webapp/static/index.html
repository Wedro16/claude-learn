claude-learn

Claude does the work and makes sure you can own it. How much it teaches depends on what you already know.

API
Try it:
  1. Pick a learner and a task, then Start. Claude does the task, adapted to that learner.
  2. Answer Claude's question and fill the TODO(learner) gap (or ask for Claude's version), then Submit.
  3. Watch the learner model on the right update. Then run the same task as a different learner and compare.

Learner histories are synthetic demo data. Your sandbox is private to this browser.
